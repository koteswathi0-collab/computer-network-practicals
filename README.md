## 📚 Practical 01: Network Hardware Identification and Connectivity Troubleshooting

### 🎯 Aim
To identify standard network hardware components such as Network Interface Cards (NICs), switches, routers, and network cables, and use network configuration and diagnostic commands to troubleshoot connectivity issues in a small office network.

### 📖 Objectives
- Understand the fundamentals of computer networking.
- Identify different network hardware components and their functions.
- Understand the role of NICs, switches, routers, and Ethernet cables.
- Learn basic network configuration concepts.
- Execute networking commands to examine connectivity.
- Diagnose and troubleshoot common network problems.

### 🖥️ Network Hardware Components

| Component | Description |
|---|---|
| NIC | Connects a computer to a network. |
| Switch | Connects multiple devices within a LAN. |
| Router | Connects different networks and forwards data packets. |
| Ethernet Cable | Provides a wired connection between network devices. |

### 💻 Networking Commands

The following commands are used for network configuration and troubleshooting:

| Command | Purpose |
|---|---|
| `ipconfig` | Displays IP configuration. |
| `ipconfig /all` | Displays detailed network information. |
| `ping` | Tests network connectivity. |
| `tracert` | Identifies the route taken by packets. |
| `nslookup` | Performs DNS lookups. |
| `arp -a` | Displays IP-to-MAC address mappings. |
| `getmac` | Displays MAC addresses. |
| `netstat` | Displays active network connections. |
| `route print` | Displays the routing table. |
| `hostname` | Displays the computer name. |

### 🔍 Key Concepts Covered
- Local Area Network (LAN)
- Internet Protocol (IP) Address
- MAC Address
- Subnet Mask
- Default Gateway
- Domain Name System (DNS)
- Dynamic Host Configuration Protocol (DHCP)
- Address Resolution Protocol (ARP)

### 🛠️ Tools and Requirements
- Windows Computer / Laptop
- Command Prompt (CMD)
- Network Interface Card (NIC)
- Ethernet Cable
- Network Switch
- Router

### 📋 Practical Procedure
1. Identify the NIC, switch, router, and Ethernet cables.
2. Understand how network devices are interconnected.
3. Connect the computer to the network.
4. Execute `ipconfig /all` to inspect network configuration.
5. Use `ping` to test connectivity.
6. Use `nslookup` to verify DNS resolution.
7. Execute `tracert` to examine the network route.
8. Use additional diagnostic commands to investigate connectivity issues.
9. Record observations and analyse the results.

### 🎓 Learning Outcomes
After completing this practical, I learned how to:
- Identify commonly used networking hardware.
- Understand how devices communicate within a network.
- Examine IP and MAC addresses.
- Execute basic networking commands.
- Identify common connectivity issues.
- Apply basic troubleshooting techniques.
